# Кимчи-кафе Глеба Ли

Браузерная кулинарная игра: собери кимчи по рецепту вместе с Глебом Ли и накорми гостей.

- Играть: https://aasolo.github.io/kimchi-gleba/
- Настоящее кимчи: [@hoplalalei](https://instagram.com/hoplalalei)
- Игру сделал: [@misterandreos](https://instagram.com/misterandreos) · [сайт](https://aasolo.github.io/misterandreos/)

Работает на iPhone, Android, планшетах, Windows и Mac — прямо в браузере, без установки.
